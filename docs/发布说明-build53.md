Pan's Desktop 1.0.0（Build 53）

- 当前正式版本的干净软件包，Apple Silicon / arm64，macOS 14 构建目标。
- 包含透明分区、独立锁定、按内容放大、搜索、引用/收纳等当前功能。
- 不含现有个人文件、图片、分区配置或操作记录。
- 解压后将整个“Pan's Desktop”文件夹放到有读写权限的位置，再打开其中的 app。
- 只有本地签名，没有 Apple Developer ID 签名和公证；在另一台 Mac 可能出现安全提示。
- 不会自动同步旧电脑的文件或引用路径。

安装前可用随附 SHA256SUMS.txt 校验下载包。
