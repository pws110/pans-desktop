# Pan's Desktop 1.0.0 · Build 54

## English

- Chinese and English interface, following the system's preferred language.
- English menus, search, tooltips, dialogs, error messages, and activity controls.
- English installation, update, backup, and build instructions: [README.en.md](https://github.com/pws110/pans-desktop/blob/main/README.en.md).
- Existing partition names, file names, paths, and settings stay unchanged. File operations and independent locking retain their existing behavior.

Download **PansDesktop-v1.0.0-build54-macOS-arm64.zip** for Apple Silicon (M-series) Macs. Keep the entire outer folder in a writable location and open the app inside it. Choose **Add References Only (Keep Originals)** in each partition if you want originals to stay in place; Collect mode moves files.

Minimum build target: macOS 14; not every macOS version has been tested individually. This package is locally signed and **not Apple-notarized**. Another Mac may display a system security prompt.
